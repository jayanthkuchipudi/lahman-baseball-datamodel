Sports Data Model – Baseball (Lahman Database)
Overview

This project focuses on recreating the Lahman Baseball Database as a fully documented,
cloud-ready relational data model. The goal is to design a core sports data model that
can be deployed initially on Azure and later extended to AWS, GCP, and Oracle.

The Lahman database is a widely used open dataset maintained by SABR and contains
comprehensive historical baseball statistics including players, teams, batting, pitching,
fielding, awards, and more.

Source:
https://sabr.org/lahman-database/

Objectives

Recreate the complete Lahman Baseball relational database

Capture metadata for every table and column

Produce an Entity Relationship Diagram (ERD)

Deploy schema in cloud environments (starting with Azure)

Version-control all database artifacts in GitHub

Ensure portability across multiple cloud providers

Technology Stack

Database: Azure SQL / MySQL / PostgreSQL

Cloud Platforms: Azure (primary), AWS & GCP (future)

Data Modeling Tool: MySQL Workbench

Version Control: GitHub

Containerization: Docker

Source Data: Lahman Baseball Database (CSV)
